# NTPUSU Regulation Typesetting

**國立臺北大學學生自治會法規排版工具**是為臺北大學學生會網站法規資料庫設計的排版工具。

使用者可以依照指定格式，輸入法規的純文本內容，再由 JavaScript 程式處理後，輸出成 HTML + CSS 格式，貼上到學生會的法規資料庫。

## 使用方式
1. 點擊 [NTPUSU Regulation Typesetting](https://ntpusu.github.io/ntpusu-regulation-typesetting/) 進入使用頁面。
2. 第一列輸入框（左邊兩個小的，右邊一個大的），分別是標題、最近異動、沿革欄位。請在此輸入法規的標題、最近異動日期（範例「修正日期：2024年6月8日」），以及詳細沿革。
3. 依照下列〈會網法規排版格式〉說明，輸入法規的純文字內容。範例可參考使用〈會網法規排版格式〉排版後的《[國立臺北大學學生自治會組織章程](https://github.com/ntpusu/legislative-data/blob/main/data/bylaws/6001.md?plain=1)》（請從第二條 `---` 線的下方開始查看）。
    - **編章節、條號：** 不用縮排。
    - **項（及不分項條文）：** 每行前面加上一個全形空白「`　`」。
    - **款、目：** 以「一、」、「（一）」開頭；注意，「目」的括號是全形。
4. 輸入完成後，點擊輸入框下面的 `產生 HTML 原始碼` 按鈕，就會在右邊的輸出框看到標記好格式的法規，最終呈現結果也會顯示在下面預覽。
5. 請瀏覽下方的預覽結果，確認都沒問題（如果有問題，請回到第 2 步，修改輸入框中的內容）後，點擊輸出框下的藍色 `Copy` 按鈕，就會自動將標記好格式的法規複製到你的剪貼簿中。
6. 登入 R-page 後台，把標示好格式的結果，貼上到該則法規資訊的 [編輯資訊] - [詳細說明] 處。請於該處選擇 [HTML] 模式，並不要開啟「HTML編輯/預覽」。
7. 原先的純文字，建議自己留好備份。未來修改時，就可以以此為基底，不用每次都重新把 Word 檔案，再按本工具的格式重新調整法規內容。我們更建議，未來大家修改法規時，也就直接照這個格式來，因為若搭配我們的法規系統，甚至可以直接產生修正對照表、符合《中央法規標準法》之公告格式，就不用大費功夫另行製作。
